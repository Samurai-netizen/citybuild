# HTTP endpoints

Source: the OpenAPI `3.1.1` document the API's build writes (`server/src/CityBuilder.Api/obj/openapi/CityBuilder.Api.json`). The normative specs stay in `core-instructions/`; this page shows the code as built.

In the order the server maps them. "Bearer" means the request sends the access token in the header `Authorization: Bearer` followed by the token; without a valid token the answer is 401 `AUTHENTICATION_REQUIRED`. Every error answer is Problem Details with a code from [errors.md](errors.md). `POST /api/v1/auth/dev-login` is mapped only in Development with `Auth:DevLoginEnabled` on, and `GET /health` (health checks) is not part of the document.
