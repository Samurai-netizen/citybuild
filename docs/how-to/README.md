# How-to Guides

Worked, step-by-step guides for common changes, for people and AI coders. Each guide is written by the task that first
creates the capability, and every later change to that area keeps it valid. The checklists in
`core-instructions/19-change-recipes.md` are the short form; these guides add a worked example.
