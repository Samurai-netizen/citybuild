# Balance reports

What the balance simulator (`tools/BalanceSim`) shows about the content, compared with the goals of
`core-instructions/24-economy-design.md`. Each report names the content version and the simulator commit it ran on, so its numbers can
be reproduced. How to run the simulator: [run-balance-simulator.md](../how-to/run-balance-simulator.md).

| Report | Content | Task | What it decides |
|---|---|---|---|
| [REPORT-mvp-1.md](REPORT-mvp-1.md) | `mvp-2`, after: `mvp-3` | M0-68, M0-69 (M0-A) | The proposed Era I number changes, the owner's picks, and the runs after them |

A report is written once, by its task. A later content change gets a new report (`REPORT-mvp-2.md`, …), or a before/after section
appended by the task that applies the change (M0-69).

Last updated: M0-68 (M0-A)
