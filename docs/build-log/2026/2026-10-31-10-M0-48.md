## Problems and surprises
- I took `Register(web.Abort)` for a bug that would stop every timeout, because the test's own comment says Abort works only on the main thread. CR-0004 had measured the opposite, and the comment was wrong. Comment corrected (decision 5).
- `AllocatingGCMemory` is an extension method and needs `using UnityEngine.TestTools.Constraints` plus the `Is` alias; the first run did not compile.
