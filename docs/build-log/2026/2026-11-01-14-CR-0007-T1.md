## Problems and surprises
- `PanelSettings` was `ConstantPhysicalSize` (a unit is a 96th of an inch on the device's density), not `ScaleWithScreenSize` as the CR assumed from the reference resolution field.
  My first change of the reference resolution therefore did nothing; `SharedLookTests` found it (the test asserted the mode). This is the real cause of "everything is too big" on a phone.
- A UI Toolkit panel on a render texture scales by the Editor's screen size, not by the texture's, so the screenshots had to emulate the scale by hand. The first set was drawn about 10 %
  too big; it was redone.
- Unity's `Burst` compiler thread crashed once in a PlayMode run (a segfault in the log, exit 139); the next run passed.
- The screenshots are of a flat green ground with sample data, not of the real city, and use the Editor's default font. The look on a device may differ.
