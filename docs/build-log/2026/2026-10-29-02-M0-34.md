## Problems and surprises
- The .NET 10 exception handler middleware logs **nothing** for an exception an `IExceptionHandler` answers (probed: only the startup lines), so
  without decision 7 an `INTERNAL_ERROR` would have left no trace.
- The in-memory suite could not have found the chunked-413 gap (decision 8): the test server has no body limit. Only the real server did, which is
  why the by-hand run stays in the task's Definition of Done for the pieces the in-memory server cannot reproduce.
- `Retry-After` is the window's length, not the time left in it: the framework's fixed-window lease reports a whole window. It is an upper bound
  (documented in `05` and `07`); an exact value needs our own bookkeeping, which nothing needs yet.
- macOS `sed -i` takes a backup suffix argument; a chain of `sed -i … &&` silently did nothing once. The edits were redone with Python.
