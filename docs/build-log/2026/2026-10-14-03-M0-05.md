## Decisions
<!-- Every decision, when it is made, including small ones. Scope: local | project-wide (→ 12-decisions.md row) | architectural (→ ADR). -->
| # | Decision | Alternatives considered | Why | Scope |
|---|---|---|---|---|
| 1 | `AppInfo` is a `public static class` in `CityBuilder.Client.Core` whose `Version` is `Application.version` (Unity's `PlayerSettings.bundleVersion`, `0.1.0` today). The EditMode test checks that it equals the bundle version and is dotted numbers | A `const string` in code (a second copy of the version that can drift from the project setting); a generated file written at build time (a build step nobody asked for); drop the test (the follow-up allows it, the spec asks for it) | The M0-04 follow-up says nobody defines `AppInfo`. The version of the client build already lives in the project settings, and M0-58 only needs to read it for the `X-Client-Version` header. It is read-only, so there is no static mutable state | local |
| 2 | The PlayMode tests cover: one `GameRoot` in the Bootstrap scene with no error logged, the label text, and a reload that keeps one root. Not covered: "another scene spawns nothing" and "a pre-placed root is kept" | Commit a second scene file made by an editor script; load the template's `SampleScene` through `EditorSceneManager.LoadSceneInPlayMode` (`#if UNITY_EDITOR`) | Both need a second scene asset that is loadable in a test. `SampleScene` is the template's and is to be removed (M0-04 follow-up); `SceneManager.CreateScene` does not raise `sceneLoaded`, so a test with it would pass for the wrong reason. Logged as a follow-up | local |
| 3 | "No error logged" means `LogType.Error`, `Exception` and `Assert` collected by an `Application.logMessageReceived` handler that is added before the scene loads. Warnings are not counted. A test that scene 0 of the build list is `Assets/Scenes/Bootstrap.unity` is part of the class | Count warnings too; rely only on the test framework's own failure for an unexpected `LogError`; no build-list test | The spec says errors; M0-04 saw zero warnings, but a graphics driver or a package can add one that the project does not own, and a flaky warning check would teach the next coder to ignore the suite. The framework's own check does not name what was logged. The player starts at scene 0 (`client/README.md` step 4), and the owner's template state has an unticked second scene, so the list is worth a guard | local |
| 4 | The scripts write the NUnit XML and Unity's log to `client/CityBuilder/Logs/test-unity/` (ignored by git), run **both** platforms even when EditMode fails, and treat these as a failed run: a failed test, a non-zero Unity exit code, no result file, an unreadable result file, and **zero tests run**. A result file from an earlier run is deleted first. Skipped tests are printed per run and do not fail it | Stop at the first failing platform; accept an exit code of 0 with zero tests; a results folder in `Temp/` (Unity deletes it at start) or a new top-level `artifacts/` folder; fail on skipped tests | One run shows the whole picture (each run is about 10 s). A suite that ran nothing is the quiet way for tests to disappear (G-Tests), and Unity itself exits 0 then. `Logs/` is already ignored and survives the start of the Editor. A skipped test is visible in the summary; a platform-specific skip can be legitimate, so the script does not decide for the reviewer | local |
| 5 | The scripts accept the path of a macOS `Unity.app` folder as well as the executable, and exit 2 (not 1) for a setup problem, so a caller can tell "the tests failed" from "nothing was run". The message names the editor version read from `ProjectSettings/ProjectVersion.txt` | The executable only; one exit code for everything | The Hub shows the folder, and people paste what they see. CI (M0-62) and `quality.sh` need to tell the two apart | local |
| 6 | The `.ps1` starts Unity with `Start-Process -Wait -PassThru -NoNewWindow` | A plain `& $unity …` | `Unity.exe` is a GUI-subsystem program: PowerShell does not wait for it, so the exit code and the result file would be read too early | local |
