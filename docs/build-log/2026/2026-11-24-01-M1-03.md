  link walkable instead of "one building per grid tile" (the grid grew; the case's workers, couriers and chains are unchanged).

  migration"; the reset deletes it, so they migrate up to `AddBuilderQueue` now, as `add-migration.md` says; no assertion changed.
- `dotnet ef migrations remove` needs a database connection; with none it fails, so a regenerated migration's files were deleted by hand
  (never applied) and the model snapshot restored from git.
