## Sessions

### Session 1 — 2026-10-31 · Claude Code / claude-sonnet-5-5
- **Plan:**
  1. The vocabulary in `CityBuilder.Client.Net`: `CommandKind`, `CommandIntent` (one factory per command), `CommandPolicy` (attempts, backoff,
     debounce, with validation), `CommandPhase`, `PendingCommand`, `CommandOutcome`; tests for the intent and the policy.
  2. `CommandSender`, the immediate path: one `requestId` per intent, the retry loop (network error, timeout, 5xx, `CONCURRENCY_CONFLICT`; never a
     4xx business error), `SnapshotMapper.Apply` on success, the pending list and `PendingChanged`; EditMode tests over `ApiClient` and a fake
     transport (same `requestId` on every retry, 422 not retried, success after two timeouts applies exactly one snapshot, backoff 0.5 / 1 s).
  3. The worker stepper path: `assign-workers` intents coalesce per building behind a debounce of ~400 ms, and a send waits for an earlier
     one of the same building to finish; tests (five rapid taps send one command with the final value, superseded intents say so, order).
  4. `GameRoot` builds the sender once connected (the one composition root); `FakeTransport` learns to time out.
  5. Docs per Docs impact, Definition of Done, self-review, PR.
