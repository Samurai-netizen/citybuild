     and effects flat with explicit nulls), `Endpoints/ContentEndpoints.cs`; contract tests on the raw JSON (every name and type,

     `AUTHENTICATION_REQUIRED` (05) for every `/api/v1` endpoint; the existing authentication tests keep their cases and check the body.
  3. **`GET /api/v1/city`:** `SettleCityResult` gets the server time and the stored `state_version` the snapshot needs; the snapshot DTOs
     and a mapper reusable by the command endpoints (M0-29 maps `CommandSuccess` with it); `Endpoints/CityEndpoints.cs` runs `SettleCity`
     for the token's player. Tests: the mapper on hand-built cities (every phase, every stall reason, a frozen cycle, an empty research
     slot, the settlement block) as raw JSON in the fast suite; over HTTP on PostgreSQL: dev login, then `GET /city` at two clock
     readings (the first settles and saves, a repeat in the same second changes nothing), another player's city never shows,
     unauthenticated → 401.
