## Problems and surprises
- **Review finding 1 (fixed, decision 17):** the first `/content` had no `startingCity`, but the validating content factory the client uses in M0-38
  requires it. Found while checking what the client needs from the response; fixed with two round-trip tests (decision 18).
- **My arithmetic, not the engine (fixed in the test):** the settle-after-100-s test expected 6 production cycles; the first cycle ended at 1005,
  so 7 is right. Every value of the exact-text test was checked by hand against the engine's rules before it was frozen.
- **Docs promised more than the spec (decision 14):** the Application module doc and ADR-0005 said `GET /city` would log the clock-behind warning
  in M0-28; the task spec does not, so it moved to M0-35 and the owner is asked in the report.
- The server writes `'` raw in JSON strings and `JsonSerializerOptions.Web` writes `\u0027`; texts compared across the two go through `JsonNode`
  first (`ContentFromResponse.Normalize`).
- No agents were used (OD-9). Self-review: line by line (the task touches security and the settle result): the 401 path, the version arithmetic
  (checked against PostgreSQL), the endpoints' thinness, and the nulls and orders of both bodies. Besides finding 1 it found nothing blocking.
