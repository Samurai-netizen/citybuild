## Problems and surprises
- The first try of the stalled look failed: the `.mat` file with `_EMISSION` in `m_ValidKeywords` and a black emission came back from Unity without the keyword. URP's material code keeps the keyword on only when the material is not flagged `EmissiveIsBlack` (`m_LightmapFlags` 4); it needed an emission above zero (0.002, under one 8-bit step) and `m_LightmapFlags` 2. Unity leaves the file unchanged now (the mirror's copy equals the repository's after the run), and `ArtImportTests` guards the three values.
