## Problems and surprises
- **xUnit v3 4.x defaults to Microsoft Testing Platform v2**, which refuses to run under VSTest-mode `dotnet test` on the
  .NET 10 SDK ("Testing with VSTest target is no longer supported by Microsoft.Testing.Platform on .NET 10 SDK and later",
  xUnit 4.0.0 release notes, 2026-08-14). CI and `AGENTS.md` use VSTest syntax (`dotnet test <slnx> --filter "Category!=Integration"`).
  VSTest needs the adapter `xunit.runner.visualstudio`, which is not on the approved list in `14` (G-Dependency).
