| 3 | The request DTO refuses what isn't the contract during binding: `[JsonUnmappedMemberHandling(Disallow)]`, `[JsonRequired]` on every field, `[JsonNumberHandling(Strict)]` | Read the body by hand; accept and ignore unknown fields; nullable fields checked in the endpoint | The task asks for 400 on unknown properties; a missing `x` would read as column 0; the web defaults read `"2"` as a number (found by a test).
