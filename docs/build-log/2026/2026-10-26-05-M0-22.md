## Problems and surprises
- EF Core wraps PostgreSQL's lock timeout from a query in an `InvalidOperationException`, so `LockTimeouts.IsLockTimeout` walks the inner
  exceptions, and the test looks for the `PostgresException` anywhere in the chain.
- Npgsql can't read a SQL row value as a .NET tuple (a `Select` to `ValueTuple` failed with "Could not read a PostgreSQL record"); the test
  projects to an anonymous type.
- PR #33 (M0-21) wasn't merged at the start; the branch is stacked on it (decision 1, Owner input).
