- Finish review (session 3): one line of `ResearchScreen.Elements.Find` ran past the file's width after the `Scroll` lookup was added; rewrapped.
  No other finding.
- Session 1 could not compile or run anything and its code broke a project rule (static state) and missed parts of the spec; session 2's review
  (Session 2 → findings) fixed them. Session 2 still cannot run Unity, so the C# and the UXML are checked by reading, the repository tests and the
  browser approximation only.
