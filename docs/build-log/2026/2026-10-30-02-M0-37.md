- **Start:** PR #48 (M0-36) is merged (`3555c8a`); the branch starts from that `main`, and M0-36's board row goes to `Done` with this
  task. Model: Sonnet 5.5 (`[S]`). No agents (OD-9). Not `[PLAN]`: no approval gate; decisions are logged as made.
- **What exists** (read first): the `CityBuilder.Client.Net` assembly is an empty skeleton (asmdef with `Newtonsoft.Json.dll`, manifest
  names `com.unity.modules.unitywebrequest` and `com.unity.nuget.newtonsoft-json` 3.2.2); EditMode tests exist for `AppInfo` and the
  engine in Unity; `05` and the server's `Contracts/` records are the wire format; the server runs on the dev database (Docker is up).
- **Plan:**
  1. **DTOs, `ApiError`, JSON settings and the response parser:** the records of `05` (snapshot, content, dev login, the four command
     bodies) as classes with `long` quantities; `ApiError { Code, Status, Detail, TraceId }` and the code list; one `ApiJson` settings
     object (camelCase, enums as strings, no `DateTime` parsing); `ApiResponseParser` turns (status, body) into a value or an
     `ApiError` (malformed JSON, a 502 HTML body, an empty body, a Problem Details body). Real server responses copied into
     `Tests/Fixtures/` (content, snapshots, one answer per reachable error code); EditMode tests for all of it.
  2. **`ApiClient`:** an `IApiTransport` seam (a fake in tests), `UnityWebRequestTransport` (the real one), `ApiClientSettings`
     (a `ScriptableObject` asset: base URL, timeout), `CancellationToken`, a bearer token held in memory, one method per endpoint of `05`;
     EditMode tests with a fake transport (URL, headers, body, timeout, network error, cancellation). `link.xml` for IL2CPP.
  3. **Docs and finish:** module doc `CityBuilder.Client.Net.md`, `09`, `client/README.md`, `docs/getting-started.md` if needed,
     CHANGELOG; Unity compile check and `test-unity.sh`; the real `UnityWebRequestTransport` walked once against the running server.
