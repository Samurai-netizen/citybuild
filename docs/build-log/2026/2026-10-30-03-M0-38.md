## Decisions
<!-- Every decision, when it is made, including small ones. Scope: local | project-wide (→ 12-decisions.md row) | architectural (→ ADR). -->
| # | Decision | Alternatives considered | Why | Scope |
|---|---|---|---|---|
| 1 | `Net` and `Presentation` reference `CityBuilder.Simulation` (asmdef, `09` table, `ClientAssemblyTests` expectations) | build the content in `Core` (cannot: it cannot name the Net DTOs); a Simulation-free intermediate type (a second copy of the content shape) | The task says "map DTO to `Simulation.GameContent` through the same validating factory": the DTOs live in `Net`, and asmdef references are not transitive, so `Net` must name `GameContentData`; `Presentation` must name `GameContent` to hold the result. `03` already lets every `Client.*` assembly use the Simulation package. The test change adds a reference, it loosens nothing (G-Tests: reason written here) | local |
| 2 | The dev display name is a field of `ApiClientSettings` (`devDisplayName`, default `dev1`, the example of `05`) | a second `ScriptableObject` "DevSettings" with its own hand-written asset | One asset to find and edit; the field initializer is the default for an asset saved before the field existed. `devtest` (OD-14) is for hand runs, which pass it explicitly | local |
| 3 | The stored token is kept with the display name it was issued for, without an expiry; a refused token (401) is dropped and the flow logs in once more | store `expiresAtUtc` and compare with the device clock | The server decides what is expired; no client clock is involved (`02` rule 3 in spirit); one code path for every reason a token stops working (expiry, a new signing key, a reset database) | local |
