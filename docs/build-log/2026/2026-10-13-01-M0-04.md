## Problems and surprises
- The first headless import failed with "Scripts have compiler errors": the owner's baseline (Input System 1.12.0) does not compile on
  Unity 6000.3.25f1, and the editor's own bundled Universal 3D template (`com.unity.template.3d-cross-platform-17.0.14`) pins the same
  version. Fixed by decision 4. The manifest also lists URP 17.0.1; the Editor resolves it to 17.3.0 in `packages-lock.json` on its own.
- The editor itself says which package versions it supports: `Unity.app/Contents/Resources/PackageManager/Editor/manifest.json` lists a
  `minimumVersion` per package. I found it only through the review; the first fix (Input System 1.14.2) compiled but was below the
  minimum (1.20.0). Check that file first when a package pin is in question.
- A first set of parallel Bash calls that each started with `cd` raced over the shared working directory and reported missing folders
  that exist; commands now use absolute paths and no `cd` in parallel calls.
