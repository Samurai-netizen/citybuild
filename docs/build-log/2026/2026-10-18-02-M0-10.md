## Problems and surprises
- Every new test passed on its first run: the rules were built in M0-09, and no engine bug turned up. The evidence that the tests can fail is
  the mutation check. The first auto-staffing test was too weak ("always max" passed it); working out what each test catches found it
  before the run, and M13 confirmed the fix (decision 12).
- The order of research and building completions within a second is still not observable (M17), as M0-09 found.
- The first mutation run printed the failure counts but no test names: macOS `sed -E` has no `\s`. `[[:space:]]` fixed it, and the run was
  repeated.
